📊 Manhattan Distance Explained

The Manhattan distance heuristic calculates how far each tile is from its goal position:

h(n) = Σ |current_row - goal_row| + |current_col - goal_col|

Current distance: 0 (Lower is better, 0 = solved)

The A* algorithm uses this value to find the optimal solution path.
